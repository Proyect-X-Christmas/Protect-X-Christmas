# Project X Christmas — Primera edición

Sitio estático en HTML, CSS y JavaScript, sin dependencias ni compilación.

## Abrir en Visual Studio Code
1. Extrae el ZIP completo y abre la carpeta `project-x-christmas`.
2. Abre `index.html` en tu navegador. También puedes usar la extensión Live Server y su opción «Open with Live Server».
3. Mantén `index.html`, `styles.css`, `script.js` y la carpeta `assets` juntos.

## Publicar en un repositorio
Sube el contenido de esta carpeta a tu repositorio. Para un alojamiento estático, configura la raíz que contiene `index.html` como directorio público. No hay paso de compilación. Todos los archivos tienen rutas relativas, por lo que también funcionan en un subdirectorio.

## Personalización
- Textos, precios, colaboradores y enlaces: `index.html`.
- Colores, espaciados y tamaños: `styles.css`, variables al inicio.
- Menú y croquis ampliable: `script.js`.
- Imágenes originales: `assets/`.
